# Формальный контроль PE2030

Этот раздел содержит банки вопросов для обязательного по академическим правилам формального контроля (зачёт/экзамен) — отдельно от практического оценивания, описанного в [06_assessment_model.md](../course/06_assessment_model.md).

## Назначение и границы

Формальный контроль — административный шлюз, а не замена портфелю инженерных эпизодов. Он подтверждает владение языком курса и способность перенести натренированные за семестр манёвры на новую, ранее не виденную ситуацию — в пределах одного человека и ограниченного времени. Основным источником итоговой оценки компетенций остаётся портфель свидетельств, собираемый на протяжении семестра.

Подробное обоснование этой границы, формат билета и принцип «открытость условий» применительно к экзамену — в самих банках вопросов.
