# Общие шаблоны для семинаров PE2030

> См. [11_seminar_design_template.md](../11_seminar_design_template.md), раздел «Хранение материалов семинара» — здесь хранятся только формы и шаблоны, не привязанные к сюжету одной лекции. Материалы, специфичные для конкретной лекции (закрытые карточки её ситуации и т.п.), живут в `seminar_assets/` этой лекции, а не здесь.

## Файлы

- [`fact_interpretation_table.md`](fact_interpretation_table.md) — пустой бланк «факт / интерпретация / пожелание / решение / неизвестное». Первое использование — семинар A лекции 1; переиспользуется в любой лекции, где нужно разобрать пакет материалов на составные части, прежде чем в модель этой лекции войдёт более специфичный инструмент.
- [`role_card_format.md`](role_card_format.md) — общий формат закрытой ролевой карточки (что обязательно должно быть в карточке, чтобы ролевая игра работала — см. пояснение в файле). Не содержит конкретных ролей — это делает `seminar_assets/` конкретной лекции.
- [`constraint_source_table.md`](constraint_source_table.md) — бланк «ограничение — источник — владелец — последствие нарушения», введённый содержательной моделью лекции 2. Переиспользуется везде, где нужно разобрать заявленное ограничение или конфликт сторон (например, лекция 17).
- [`audience_decision_criteria_table.md`](audience_decision_criteria_table.md) — бланк «аудитория — решение пользователя — результат — критерий приёмки — критерий эффекта», введённый содержательной моделью лекции 3. Переиспользуется везде, где нужно специфицировать инкремент для конкретной аудитории.
- [`adr_template.md`](adr_template.md) — бланк Architecture Decision Record, введённый содержательной моделью лекции 4. Переиспользуется в любой лекции, где решение нужно зафиксировать явно (лекции 10, 11, 16).
- [`scoped_delegation_prompt.md`](scoped_delegation_prompt.md) — четыре обязательных элемента запроса к AI с явной границей делегирования, введённые содержательной моделью лекции 5. Переиспользуется при любом делегировании шага реализации, включая более сложные случаи агентного делегирования в лекции 15.

## Статус

Черновик, начат 2026-07-27 вместе с первыми семинарами лекции 1. Пополняется по мере того, как в новых семинарах обнаруживается материал, действительно нужный без изменений в нескольких лекциях, — не создаётся заранее «про запас».
