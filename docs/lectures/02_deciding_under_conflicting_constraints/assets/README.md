# Материалы для лекции 2

Этот каталог содержит заранее подготовленные AI-артефакты для лекции 2. Материалы ролевой игры «заказчик — исполнитель» (закрытые карточки сторон) — в [`../seminar_assets/`](../seminar_assets/), не здесь, см. [11_seminar_design_template.md](../../../course/11_seminar_design_template.md).

## Файлы

- [`ai_comparison_matrix.md`](ai_comparison_matrix.md) — предложение AI: пространство альтернатив и явные профили весов. Используется в **блоке 6** сценария лекции.

## Как использовать на занятии

`ai_comparison_matrix.md` показывается как есть. Видимые (не закрытые) требования шести сторон для слайда 2 [`../slides.md`](../slides.md) берутся из открытой части [`../seminar_assets/stakeholder_cards.md`](../seminar_assets/stakeholder_cards.md) — скрытые детали карточек не должны попадать в руки студентов до семинара.

## Статус

Черновик. Как и в лекции 1, технические и организационные детали выбраны ради правдоподобия примера, а не как предписание для реального пилота `pe2030-air-quality-pilot`.
