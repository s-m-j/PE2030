# Материалы для лекции 9

## Файлы

- [`ai_two_framings.md`](ai_two_framings.md) — предложение AI: два противоположных, одинаково убедительных обоснования (продолжать / развернуться) на основе одних и тех же фактов, различающихся только формулировкой промпта. Используется в **блоках 2 и 6** сценария ([../script.md](../script.md)).

## Как использовать на занятии

В блоке 2 оба ответа раздаются без подписи промптов — важно, чтобы аудитория попыталась определить «более верный» ответ, не зная, как были сформулированы запросы. Промпты раскрываются только в блоке 6, после того как зал уже увидел оба тезиса лекции о невозвратных затратах и техническом долге.

## Статус

Черновик, учебный пример. Оба ответа AI написаны ради иллюстрации зависимости вывода от формулировки запроса, а не как рекомендация по реальному направлению развития `pe2030-air-quality-pilot`.
