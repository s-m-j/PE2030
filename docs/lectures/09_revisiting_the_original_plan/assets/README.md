# Материалы для лекции 9

## Файлы

- [`ai_three_framings.md`](ai_three_framings.md) — предложение AI: три ответа на по-разному сформулированные запросы. Первые два — противоположные, одинаково убедительные обоснования (продолжать / развернуться) на основе одних и тех же фактов, различающиеся только формулировкой промпта. Третий, по прямому запросу «не рекомендуй ничего», честно раскладывает известное, предполагаемое и то, как разные веса меняют вывод, не занимая позицию. Используется в **блоках 2 и 6** сценария ([../script.md](../script.md)).

## Как использовать на занятии

В блоке 2 все три ответа раздаются без подписи промптов — важно, чтобы аудитория попыталась определить, какой из трёх — разбор без позиции, а какие — framing, не зная, как были сформулированы запросы. Промпты раскрываются только в блоке 6, после того как зал уже увидел тезисы лекции о невозвратных затратах и техническом долге.

Важно на занятии не называть третий ответ «более честным» — framing первых двух ответов не то же самое, что нечестность: оба добросовестно используют реальные факты, просто с разным весом.

## Статус

Черновик, учебный пример. Все три ответа AI написаны ради иллюстрации зависимости вывода от формулировки запроса, а не как рекомендация по реальному направлению развития `pe2030-air-quality-pilot`.
