# Материалы для лекции 6

## Файлы

- [`coverage_gap_review.md`](coverage_gap_review.md) — тесты, написанные самой командой (32 теста, 95% покрытия) для кода из лекций 4–5, не покрывающие границу суток; и последующее ревью AI, сопоставляющее тесты со сценариями реального использования и находящее этот пробел, который команда затем воспроизводит на реальных данных. Используется в **блоках 1–2** сценария ([../script.md](../script.md)) — часть 1 (тесты) показывается сначала, часть 2 (ревью и воспроизведение) — после реакции зала.

## Как использовать на занятии

В блоке 1 показывается только сводка покрытия (95%, все зелёные) из части 1, без деталей тестов — это важно для эффекта неожиданности в блоке 2, когда аудитория получает полный текст и должна сама найти пробелы, прежде чем увидит часть 2 с ревью AI.

## Статус

Черновик, учебный пример. Код и тесты написаны ради иллюстрации разницы между покрытием и достаточностью проверки, а не как образец реальной тестовой стратегии для `pe2030-air-quality-pilot`.
