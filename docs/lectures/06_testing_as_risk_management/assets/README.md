# Материалы для лекции 6

## Файлы

- [`ai_test_suite_report.md`](ai_test_suite_report.md) — предложение AI: набор из 32 тестов с 95% покрытия для кода из лекций 4–5, не покрывающий пороговое значение, отсутствие данных, расхождение часовых поясов и пометку приближённых показаний. Используется в **блоках 1–2** сценария ([../script.md](../script.md)) — сначала показывается только сводка, затем раздаётся полный текст для самостоятельного разбора.

## Как использовать на занятии

В блоке 1 показывается только сводка покрытия (95%, все зелёные), без деталей тестов — это важно для эффекта неожиданности в блоке 2, когда аудитория получает полный текст и должна сама найти пробелы.

## Статус

Черновик, учебный пример. Код и тесты написаны ради иллюстрации разницы между покрытием и достаточностью проверки, а не как образец реальной тестовой стратегии для `pe2030-air-quality-pilot`.
