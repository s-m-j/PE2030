# Обновление для семинара B: второй тип датчика

> **Роль в семинаре:** вводится в блоке 3 [`../seminar_b.md`](../seminar_b.md), после того как группы защитили свой ADR для коэффициента `0.12`.

## Новый факт

> К пилоту подключается ещё один недорогой датчик — другой модели, от другого производителя. Паспортная документация этой модели указывает соотношение чувствительности к PM2.5, отличное от того, что использовано в коэффициенте `0.12`: по паспорту новой модели соотношение ближе к `0.09`. Неясно, означает ли это, что `0.12` был неверен для первой модели, или что коэффициент вообще не может быть одним числом для всех недорогих датчиков сразу.

## Два пути — команда должна явно выбрать и обосновать

1. **Пересмотреть ADR немедленно**: завести отдельный коэффициент для новой модели (или параметризовать коэффициент по модели датчика вместо константы), не дожидаясь ответа эколога, — на основании паспортных данных, которые уже есть.
2. **Дождаться консультации эколога**: паспортное соотношение чувствительности — не то же самое, что фактическая калибровка в реальных условиях (влажность, температура, износ датчика); возможно, ни `0.12`, ни `0.09` не отражают действительность точно, и стоит подождать содержательного ответа специалиста, назначенного ответственным ещё в семинаре A.

## Материал для разбора

Ни один путь не является очевидно правильным. Путь 1 быстрее устраняет видимое несоответствие, но рискует внести столь же необоснованное число, только другое. Путь 2 медленнее, но не создаёт новую непроверенную гипотезу взамен старой. Ситуация прямо продолжает тезис 3 ядра лекции («явное решение — не то же самое, что обоснованное») — паспортное значение `0.09` выглядит более авторитетным просто потому, что взято из документа производителя, а не потому, что оно действительно точнее для условий пилота.

**Дополнительно (открытый потолок, для групп, которые справились быстрее):** если группа явно выбрала путь 2 и обосновала, почему ждать эколога правильнее, чем пересматривать ADR по паспортным данным, — можно раскрыть содержательный ответ эколога: «Паспортные значения обеих моделей — лабораторные, полученные в контролируемых условиях. Ни `0.12`, ни `0.09` не откалиброваны для реальных условий района с его влажностью и близостью к промышленной зоне. Нужна короткая полевая калибровка обоих датчиков против официальной станции — около двух недель наблюдений, прежде чем можно доверять числу для отчёта наружу». Это не финальный ответ, а требование дополнительной проверки — что само по себе валидный, а не уклончивый результат консультации.

Вопрос для обсуждения: если бы группа выбрала путь 1 (пересмотреть немедленно по паспортным данным), а эколог позже дал бы такой ответ, — какую цену заплатила бы команда за поспешный пересмотр?
