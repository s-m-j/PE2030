# Материалы для лекции 4

## Файлы

- [`pilot_code_review.md`](pilot_code_review.md) — код пилотного инкремента, написанный командой (не AI), с архитектурно значимым решением (нормализация разнородных данных), зашитым неявно внутри функции сравнения; и последующее ревью AI, обнаруживающее это решение. Используется в **блоке 1** сценария ([../script.md](../script.md)).
- [`adr_data_normalization.md`](adr_data_normalization.md) — контрпример: то же решение, принятое явно с самого начала, оформленное как ADR с рассмотренными альтернативами и явной границей между источником данных и логикой сравнения. Используется в **блоках 4 и 6**.

## Как использовать на занятии

`pilot_code_review.md` показывается в два приёма: сначала только код (часть 1), без подсветки проблемного места — аудитория должна найти скрытое решение самостоятельно (см. тайминг в сценарии); затем, после реакции зала, — ревью AI (часть 2). `adr_data_normalization.md` вводится позже, как ответ на вопрос «а как это можно было сделать иначе».

## Статус

Черновик, учебный пример. Код и ADR написаны ради иллюстрации архитектурной значимости решения о нормализации данных, а не как рекомендация для реализации `pe2030-air-quality-pilot`.
