# Материалы для лекции 12

## Файлы

- [`ai_incident_patch.md`](ai_incident_patch.md) — двухчастный материал: часть 1 — срочное исправление, написанное и развёрнутое дежурным инженером в панике, без участия AI (неограниченные повторные попытки без задержки и идемпотентности); часть 2 — диагностика AI с явно ограниченным мандатом только на чтение, обнаруживающая, что нагрузку создал именно человеческий патч, а не станция. Часть 1 используется в **блоке 1** сценария ([../script.md](../script.md)), часть 2 — в **блоке 2**.
- [`graceful_degradation_example.md`](graceful_degradation_example.md) — контрпример: изоляция отказа по районам, ограниченные идемпотентные повторные попытки с backoff, явная деградация, мониторинг зависания через SLO свежести данных — то, к чему команда приходит по итогам диагностики AI. Используется в **блоке 5**.
- [`incident_logs.md`](incident_logs.md) — материал для упражнения по восстановлению хронологии инцидента из неполных, частично противоречивых источников (логи, чат команды, письмо техподдержки). Хронология согласована с `ai_incident_patch.md`: скачок повторных запросов начинается в 20:16:03 (деплой патча), а не в 19:38:11 (исходная ошибка станции). Используется дважды: коротким фрагментом в **блоке 3** (проверка диагноза AI) и целиком в **блоке 8** (постмортем). Не содержит единственно правильного разбора — цель упражнения в явном разделении факта и интерпретации, а не в поиске «правильной» версии событий.

## Как использовать на занятии

Части `ai_incident_patch.md` показываются последовательно, не одновременно: сначала часть 1 (человеческий патч) как уже развёрнутое, принятое под давлением решение — важно передать ощущение реального времени инцидента. Только после того, как патч не помог, показывается часть 2 (диагностика AI). `incident_logs.md` в блоке 3 используется точечно — только фрагмент вокруг 20:16:03, чтобы подтвердить диагноз AI; полностью, по группам и без заранее подготовленного «эталонного» постмортема — в блоке 8.

## Статус

Черновик, учебный пример. Числа, время и код подобраны ради иллюстрации риска непродуманной реакции на инцидент и техники восстановления хронологии, а не как реальные инцидент-данные `pe2030-air-quality-pilot`.
