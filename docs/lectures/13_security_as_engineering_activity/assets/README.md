# Материалы для лекции 13

## Файлы

- [`ai_quick_auth_patch.md`](ai_quick_auth_patch.md) — предложение AI: срочная защита административного интерфейса паролем на веб-форме, оставляющая реальный API-эндпоинт открытым, пароль общим и захардкоженным, без журналирования. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`proper_access_control_example.md`](proper_access_control_example.md) — контрпример: проверка прав на уровне API, именные учётные записи, ограничение диапазона допустимых значений, журналирование действий. Используется в **блоке 6**.

## Как использовать на занятии

`ai_quick_auth_patch.md` показывается как уже развёрнутое, принятое под давлением решение — важно передать ощущение, что «проблема как будто решена», прежде чем аудитория найдёт оставшиеся дыры. Ситуация прямо продолжает административный интерфейс из [лекции 11](../../11_refactor_migrate_or_leave/) — стоит свериться с ним при подготовке.

## Статус

Черновик, учебный пример. Код и находки написаны ради иллюстрации разницы между security through obscurity и настоящим контролем доступа, а не как рекомендация для реальной архитектуры `pe2030-air-quality-pilot`.
