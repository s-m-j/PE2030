# Предложение AI: срочная защита административного интерфейса

> **Роль в лекции:** показывается в блоке 1–2 сценария ([../script.md](../script.md)) как уже развёрнутое исправление, принятое сразу после обнаружения поддельного источника данных. Разбор упущений открывается в блоке 2 и завершается в блоке 5.

## Промпт

```
СРОЧНО: обнаружили, что кто-то без нашего ведома зарегистрировал
источник данных через административный интерфейс — коэффициент
подобран так, чтобы занижать показания рядом с конкретным
предприятием. Интерфейс был доступен по прямой ссылке без всякой
проверки. Защити его паролем прямо сейчас.
```

## Ответ AI (как показывается студентам — уже развёрнуто)

### Изменения в веб-форме

```python
ADMIN_PASSWORD = "EcoPilot2026!"  # временный пароль, поменять позже

@app.route("/admin/sources", methods=["GET", "POST"])
def admin_sources():
    if request.method == "GET":
        return render_template("password_prompt.html")
    if request.form.get("password") == ADMIN_PASSWORD:
        return render_template("admin_sources_form.html")
    return "Неверный пароль", 403
```

### Изменения в навигации

```diff
- <a href="/admin/sources">Управление источниками</a>
+ <!-- ссылка временно скрыта из навигации до полноценного решения -->
```

### API, к которому обращается форма (без изменений)

```python
@app.route("/api/sources", methods=["POST"])
def register_source():
    data = request.get_json()
    source = SourceConfig(
        station_id=data["station_id"],
        source_type=data["source_type"],
        coefficient=data["coefficient"],
    )
    db.save_source_config(source)
    return {"status": "registered"}, 201
```

### Комментарий AI к изменению

> «Добавил проверку пароля на странице администрирования и убрал ссылку из общей навигации, чтобы её нельзя было случайно найти. Теперь доступ к форме регистрации источников защищён».

---

## Что осталось незакрытым (не показывать до блока 2 — материал для разбора)

- **Эндпоинт `/api/sources`, к которому реально обращается форма, не изменён вообще.** Проверка пароля добавлена только в обработчик HTML-страницы `/admin/sources` — сам API, принимающий регистрацию источника, по-прежнему выполнит `POST`-запрос от кого угодно, кто знает его адрес, без единой проверки. Именно этим путём, вероятнее всего, и был зарегистрирован поддельный источник — напрямую к API, минуя веб-форму.
- **Удаление ссылки из навигации — это скрытие, а не защита.** Адрес `/admin/sources` не изменился и остаётся доступным для того, кто уже его знает, сохранил в закладках или найдёт по логам, истории браузера или простому перебору распространённых путей.
- **Пароль один на всех и захардкожен прямо в коде** — при коммите он попадает в историю репозитория, включая любые публичные или полупубличные копии, форки, резервные копии. Комментарий «поменять позже» не является механизмом, обеспечивающим, что это действительно произойдёт.
- **Ни проверка пароля, ни сам API не журналируют, кто и когда зарегистрировал источник.** Даже если бы пароль был единственным способом добраться до функциональности, при компрометации пароля не осталось бы способа узнать, кто именно им воспользовался.
- **Ни одно из ограничений не применяет принцип наименьших привилегий**: тот, кто прошёл проверку пароля, получает неограниченную возможность зарегистрировать источник с любым коэффициентом для любого адреса — то есть ровно ту же возможность, которой уже воспользовался неизвестный.

Сравните с полноценным решением в [`proper_access_control_example.md`](proper_access_control_example.md).
