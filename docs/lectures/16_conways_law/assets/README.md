## Как использовать на занятии

`ai_architecture_only_fix.md` показывается в блоке 1 как убедительный, технически грамотный план — важно, чтобы аудитория сначала оценила его техническую сторону положительно и только затем, отвечая на вопросы блока 2, обнаружила отсутствие организационного измерения.

## Статус

Черновик, учебный пример. Схемы, метрики и код написаны ради иллюстрации закона Конвея и обратного манёвра, а не как рекомендация реальной организационной структуры для `pe2030-air-quality-pilot`.
