# Материалы для лекции 11

## Файлы

- [`ai_debt_scenario_model.md`](ai_debt_scenario_model.md) — первый запрос к AI: сценарная модель четырёх стратегий на реальных, честно размеченных числах, показывающая, что миграция экономически окупается в пределах года, но не затрагивающая риск перехода. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`ai_big_bang_migration.md`](ai_big_bang_migration.md) — второй запрос тому же AI: технически разумный план полной миграции реестра источников одним релизом, без пути назад и без критерия измерения эффекта. Используется в **блоке 3**.
- [`strangler_migration_plan.md`](strangler_migration_plan.md) — контрпример: та же целевая архитектура, достигнутая поэтапно, с сосуществованием старого и нового механизма и характеризующими тестами на каждом шаге. Используется в **блоке 7**.

## Как использовать на занятии

Материалы показываются в порядке двух запросов к AI: сначала `ai_debt_scenario_model.md` — важно, чтобы аудитория увидела, какие числа заданы людьми, и признала модель полезной, но неполной. Только затем показывается `ai_big_bang_migration.md`, без комментариев о риске, — аудитория должна сама найти отсутствие пути назад и критерия успеха (см. тайминг в сценарии). Материал прямо продолжает [артефакты лекции 10](../../10_understanding_before_changing/assets/) — характеризующий тест как техника уже введена там.

## Статус

Черновик, учебный пример. План и код написаны ради иллюстрации риска одномоментной миграции против поэтапной, а не как рекомендация для реальной архитектуры `pe2030-air-quality-pilot`.
