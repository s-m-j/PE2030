# Материалы для лекции 11

## Файлы

- [`ai_big_bang_migration.md`](ai_big_bang_migration.md) — предложение AI: технически разумный план полной миграции реестра источников одним релизом, без пути назад и без критерия измерения эффекта. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`strangler_migration_plan.md`](strangler_migration_plan.md) — контрпример: та же целевая архитектура, достигнутая поэтапно, с сосуществованием старого и нового механизма и характеризующими тестами на каждом шаге. Используется в **блоке 6**.

## Как использовать на занятии

`ai_big_bang_migration.md` показывается в начале лекции целиком, без комментариев о риске — аудитория должна сама найти отсутствие пути назад и критерия успеха (см. тайминг в сценарии). Материал прямо продолжает [артефакты лекции 10](../../10_understanding_before_changing/assets/) — характеризующий тест как техника уже введена там.

## Статус

Черновик, учебный пример. План и код написаны ради иллюстрации риска одномоментной миграции против поэтапной, а не как рекомендация для реальной архитектуры `pe2030-air-quality-pilot`.
