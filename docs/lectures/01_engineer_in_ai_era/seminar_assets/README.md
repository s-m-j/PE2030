# Материалы семинаров лекции 1

> Отдельно от [`../assets/`](../assets/) — там AI-артефакты (промпт + результат), здесь материалы для проведения семинара (карточки, раздатки). См. [11_seminar_design_template.md](../../../course/11_seminar_design_template.md), раздел «Хранение материалов семинара».

## Файлы

- [`role_cards.md`](role_cards.md) — четыре закрытые ролевые карточки для ролевой игры «интервью со сторонами». Используется в **семинаре B**, блок 2.

## Статус

Черновик, первое применение схемы хранения семинарских материалов. Карточки специфичны для сюжета лекции 1 — не предполагаются к переиспользованию в других лекциях в этом виде (в отличие от формы карточки, которая вынесена как общий шаблон курса — [`role_card_format.md`](../../../course/seminar_templates/role_card_format.md)).
