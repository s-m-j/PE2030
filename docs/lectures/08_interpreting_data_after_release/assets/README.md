# Материалы для лекции 8

## Файлы

- [`shared_blind_spot_analysis.md`](shared_blind_spot_analysis.md) — совместный анализ команды и AI: корректно посчитанное снижение жалоб на ~30% и причинный вывод «эффективность подтверждена», без учёта контрольного района и смены канала регистрации жалоб — оба фактора обнаруживаются позже случайно, не намеренно скрыты и не намеренно раскрыты AI. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).

## Как использовать на занятии

В блоке 1 показывается только основной раздел с совместным выводом — без раздела «Что обнаруживается позже». Этот раздел раскрывается только в блоке 2, после того как аудитория попробует сама назвать альтернативные объяснения. Важно на занятии подчеркнуть: находка не была намеренно скрыта AI и не была обнаружена AI — оба, человек и AI, работали с одним и тем же неполным контекстом.

Данные о смене канала регистрации и контрольном районе можно при желании явно связать со скрытой карточкой общественного совета из лекции 2 ([`stakeholder_cards.md`](../../02_deciding_under_conflicting_constraints/assets/stakeholder_cards.md)) — это не обязательно проговаривать вслух на лекции, но полезно держать в голове.

## Статус

Черновик, учебный пример. Числовые данные подобраны ради иллюстрации проблемы причинного вывода из корреляции и общей ошибки человека и AI, а не как реальные показатели `pe2030-air-quality-pilot`.
