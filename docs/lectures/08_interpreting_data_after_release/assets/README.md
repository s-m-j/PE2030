# Материалы для лекции 8

## Файлы

- [`ai_impact_analysis.md`](ai_impact_analysis.md) — предложение AI: анализ динамики жалоб, показывающий корректно посчитанное снижение на 37% и причинный вывод «эффективность подтверждена», без учёта контрольного района, сезонности и данных опроса. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).

## Как использовать на занятии

В блоке 1 показывается только сам отчёт с выводом — без данных контрольного района, сезонных наблюдений и опроса. Эти три фактора раскрываются только в блоке 2, после того как аудитория попробует сама назвать альтернативные объяснения.

Данные опроса прямо продолжают скрытую карточку общественного совета из лекции 2 ([`stakeholder_cards.md`](../../02_deciding_under_conflicting_constraints/assets/stakeholder_cards.md)) — стоит свериться с ней при подготовке, чтобы связь была явной для преподавателя, даже если она не проговаривается вслух на самой лекции.

## Статус

Черновик, учебный пример. Числовые данные подобраны ради иллюстрации проблемы причинного вывода из корреляции, а не как реальные показатели `pe2030-air-quality-pilot`.
