# Материалы для лекции 10

## Файлы

- [`ai_generalization_pr.md`](ai_generalization_pr.md) — предложение AI: обобщённое, автоматическое определение типа источника данных, которое молча воспроизводит исходную проблему лекции 1 (реальное превышение перестаёт обнаруживаться) для существующего района. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`safe_extension_example.md`](safe_extension_example.md) — контрпример: та же задача, решённая через характеризующий тест и явное расширение реестра источников без потери поведения первого района. Используется в **блоках 5 и 7**.

## Как использовать на занятии

`ai_generalization_pr.md` показывается в начале лекции целиком, без указания на скрытую регрессию — аудитория должна сама найти пограничный случай (см. тайминг и подсказки в сценарии). Числа в примере (40 µg/m³, коэффициент 0.12, порог 35.0) намеренно совпадают с ADR и кодом из лекции 4 — стоит сверяться с этими файлами при подготовке, чтобы связь была точной.

## Статус

Черновик, учебный пример. Числовые данные подобраны ради иллюстрации регрессии при расширении системы, а не как реальные калибровочные значения `pe2030-air-quality-pilot`.
