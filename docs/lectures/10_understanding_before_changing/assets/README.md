# Материалы для лекции 10

## Файлы

- [`ai_context_reconstruction.md`](ai_context_reconstruction.md) — первый запрос к AI: честная реконструкция контекста решений по коду, ADR, тестам и истории изменений, с явной разметкой подтверждённого, заявленного и неизвестного. AI прямо отказывается объяснить происхождение коэффициента `0.12` сверх того, что зафиксировано в ADR. Используется в **блоке 2** сценария ([../script.md](../script.md)).
- [`ai_generalization_pr.md`](ai_generalization_pr.md) — второй запрос тому же AI: обобщённое, автоматическое определение типа источника данных, которое молча воспроизводит исходную проблему лекции 1 (реальное превышение перестаёт обнаруживаться) для существующего района. Используется в **блоке 3**.
- [`safe_extension_example.md`](safe_extension_example.md) — контрпример: та же задача, решённая через характеризующий тест и явное расширение реестра источников без потери поведения первого района. Используется в **блоках 6 и 7**.

## Как использовать на занятии

Материалы показываются в порядке двух запросов к AI, не одновременно: сначала `ai_context_reconstruction.md` — важно, чтобы аудитория убедилась в его построчной проверяемости и в обоснованности отказа AI объяснить коэффициент `0.12`. Только затем показывается `ai_generalization_pr.md`, без указания на скрытую регрессию, — аудитория должна сама найти пограничный случай, опираясь на карту из первого файла (см. тайминг и подсказки в сценарии). Числа в примерах (40 µg/m³, коэффициент 0.12, порог 35.0) намеренно совпадают с ADR и кодом из лекции 4 — стоит сверяться с этими файлами при подготовке, чтобы связь была точной.

## Статус

Черновик, учебный пример. Числовые данные подобраны ради иллюстрации регрессии при расширении системы, а не как реальные калибровочные значения `pe2030-air-quality-pilot`.
