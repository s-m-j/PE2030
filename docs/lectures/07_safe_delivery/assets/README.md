# Материалы для лекции 7

## Файлы

- [`ai_deploy_script.md`](ai_deploy_script.md) — предложение AI: быстрая инструкция по развёртыванию с учётными данными в коде, без версионирования, наблюдаемости и отката. Используется в **блоке 1** сценария ([../script.md](../script.md)).
- [`safe_delivery_plan.md`](safe_delivery_plan.md) — контрпример: та же задача, решённая с версионированным артефактом, вынесенной конфигурацией, минимальной наблюдаемостью, документированным откатом и поэтапным раскрытием. Используется в **блоке 7**.

## Как использовать на занятии

`ai_deploy_script.md` показывается в начале лекции целиком, без комментариев. Ключевой момент упражнения в блоке 2 — сценарий «три недели спустя»: аудитория должна сама прийти к тому, что успешный первый запуск не гарантирует ничего о последующих неделях.

## Статус

Черновик, учебный пример. Секреты в примерах — фиктивные, использованы только для иллюстрации проблемы хранения конфигурации в коде. Схема поставки не является рекомендацией для реальной инфраструктуры `pe2030-air-quality-pilot`.
