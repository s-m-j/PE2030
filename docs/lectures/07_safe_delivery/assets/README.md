# Материалы для лекции 7

## Файлы

- [`ai_clarifying_questions.md`](ai_clarifying_questions.md) — основной пример: на недоопределённый запрос AI не выдумывает среду, а возвращает список уточняющих вопросов и минимальный нейтральный план. Используется в **блоке 1** сценария ([../script.md](../script.md)).
- [`ai_deploy_script.md`](ai_deploy_script.md) — контраст: более ранний, менее аккуратно сформулированный запрос к тому же AI даёт готовую, но небезопасную инструкцию (секреты в коде, без версии, без отката). Используется в **блоке 2**.
- [`safe_delivery_plan.md`](safe_delivery_plan.md) — контрпример: та же задача, решённая с версионированным артефактом, тремя видами конфигурации, наименьшими привилегиями сервисного аккаунта, минимальной наблюдаемостью, документированным откатом и поэтапным раскрытием. Используется в **блоке 7**.

## Как использовать на занятии

`ai_clarifying_questions.md` показывается первым, целиком, без комментариев — важно, чтобы аудитория сначала оценила ответ AI сама, прежде чем увидит контраст с `ai_deploy_script.md` в блоке 2. Ключевой момент упражнения в блоке 2 — не «три недели спустя», а прямое сравнение двух ответов одного и того же AI на разные по аккуратности запросы.

## Статус

Черновик, учебный пример. Секреты в примерах — фиктивные, использованы только для иллюстрации проблемы хранения конфигурации в коде. Схема поставки не является рекомендацией для реальной инфраструктуры `pe2030-air-quality-pilot`.
