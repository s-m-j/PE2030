# Материалы семинаров лекции 3

> Отдельно от [`../assets/`](../assets/) — там AI-артефакты (промпт + результат), здесь материалы для проведения семинара. См. [11_seminar_design_template.md](../../../course/11_seminar_design_template.md).

## Файлы

- [`audience_reaction_notes.md`](audience_reaction_notes.md) — контекстные заметки трёх аудиторий (эколог, руководитель, житель) для оценки полезности черновиков AI. Используется в **семинаре A**, блок 4. Не полноценные закрытые карточки (нет переговорного мотива) — задача роли оценить полезность, а не отстоять позицию.
- [`data_quality_update.md`](data_quality_update.md) — новый факт о приблизительном времени в трети жалоб и три пути реакции (изменить критерий / сузить границы / получить данные). Используется в **семинаре B**, блок 3.

## Статус

Черновик, первое применение схемы хранения семинарских материалов к лекции 3.
