# Материалы для лекции 3

## Файлы

- [`ai_requirements_drafts.md`](ai_requirements_drafts.md) — предложение AI: три честных черновика одного инкремента для трёх сторон (специалист / руководитель / житель), явно попрошенные командой. Используется в **блоке 1** сценария лекции ([../script.md](../script.md)).
- [`ai_requirements_single_audience.md`](ai_requirements_single_audience.md) — контрпример: документ требований, написанный так, будто аудитория одна (специалист экологической службы), потому что промпт не назвал аудиторию явно. Используется в **блоке 3**.

## Как использовать на занятии

`ai_requirements_drafts.md` показывается целиком в начале лекции без комментариев. Разбор того, что общего и что разного у трёх черновиков, происходит только после реакции аудитории. `ai_requirements_single_audience.md` вводится позже, коротко, как контраст — что бывает при менее конкретном запросе.

## Статус

Черновик. Как и материалы лекций 1–2, содержание выбрано ради правдоподобия примера, а не как образец реального документа требований для `pe2030-air-quality-pilot`.
