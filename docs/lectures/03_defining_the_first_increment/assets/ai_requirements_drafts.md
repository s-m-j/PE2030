# Предложение AI: три черновика одного инкремента для трёх сторон

> **Роль в лекции:** показывается в блоке 1 сценария ([../script.md](../script.md)) как готовый результат — без промпта. Разбор того, что общего и что разного у трёх черновиков, открывается в блоке 2.

## Промпт

```
Приоритет выбран: пилотный этап проверки качества данных существующих
датчиков и сопоставления с историей жалоб жителей за последний месяц.
Прежде чем выбирать, для кого делать первую версию, набросай по одному
варианту этого инкремента для каждой из трёх сторон: специалиста
экологической службы, руководителя центра, жителя, подавшего жалобу.
Пусть черновики будут разными по форме, но об одном и том же инкременте.
```

## Ответ AI (как показывается студентам)

### Черновик 1 — для специалиста экологической службы

Аналитический notebook: таблица по каждому датчику (доля пропусков за 30 дней, периоды статистического расхождения с ближайшей официальной станцией), сводный статус «надёжный / требует проверки / недостаточно данных», сопоставление временных меток жалоб с ближайшим по времени и месту показанием. Формат — код и таблицы, рассчитан на самостоятельную дальнейшую работу с данными.

### Черновик 2 — для руководителя центра

Один слайд: заголовок «Проверка данных за [период]», три числа крупным шрифтом (доля датчиков с полными данными, число жалоб, сопоставленных с измеримым отклонением, число датчиков, требующих внимания), один абзац текстом простым языком без терминов, один график динамики жалоб за месяц. Формат — материал, пригодный для показа на горсовете без перевода.

### Черновик 3 — для жителя, подавшего жалобу

Короткий текст на естественном языке по конкретной жалобе: «Ваша жалоба от [дата, время] сопоставлена с показаниями ближайшего датчика ([расстояние] от указанного адреса). В это время зафиксировано [значение] — [в пределах нормы / выше обычного уровня для этого времени суток]». Формат — персонализированный ответ на одно обращение, а не общий отчёт.

## Материал для разбора в блоке 2

Три черновика описывают один и тот же по сути инкремент — сопоставление данных датчиков с историей — но делают это настолько по-разному, что человек, увидевший только один из них, не узнал бы в нём тот же проект.

- **Ни один черновик не содержит скрытой ошибки.** Каждый добросовестен и достаточен для своей аудитории — это не пример «AI обмануло», а пример того, что одна словесная формулировка задачи имеет несколько равно законных прочтений.
- **Черновики расходятся не в фактах, а в том, что каждая аудитория готова и не готова принять как ответ.** Специалисту нужен воспроизводимый анализ; руководителю — три числа для устного выступления; жителю — прямой ответ на его конкретное обращение, а не отчёт о системе в целом.
- **Черновик для жителя ближе всего к тому, ради чего вообще начался разговор** (жалоба на запах из лекции 1) — но именно этот черновик легче всего забыть, если формулировать задачу абстрактно («проверка данных»), не называя жителя как одну из аудиторий явно.

Вопрос для обсуждения: если бы нужно было выбрать только один черновик как «первую версию инкремента», какой бы вы выбрали — и что при этом сознательно откладывается на потом?
