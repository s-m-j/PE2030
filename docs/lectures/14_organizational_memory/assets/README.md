# Материалы для лекции 14

## Файлы

- [`ai_onboarding_summary.md`](ai_onboarding_summary.md) — предложение AI в двух частях: часть 1 — обзор системы для нового участника, уверенно, но неверно объясняющий происхождение коэффициента нормализации данных как «калибровку по историческим данным», хотя ADR лекции 4 называет его необоснованным приближением; часть 2 — более строгий повторный запрос, приводящий к размеченной таблице «подтверждено / выведено / неизвестно» и честному признанию невосстановимого пробела. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`adr_update_example.md`](adr_update_example.md) — контрпример: короткое, своевременное дополнение к существующему ADR, зафиксированное в момент миграции лекции 11, которое предотвратило бы расхождение. Используется в **блоке 5**.

## Как использовать на занятии

Часть 1 `ai_onboarding_summary.md` показывается в блоке 1 без комментариев — аудитория должна сама, сверяясь с [ADR лекции 4](../../04_decisions_expensive_to_change/assets/adr_data_normalization.md), найти расхождение в блоке 2. Часть 2 раскрывается только после этого, чтобы показать, что более строгий запрос даёт другой результат — не потому что AI «исправилось», а потому что от него потребовали иного. Материал прямо продолжает сквозную линию коэффициента нормализации через лекции 4, 10 и 11 — стоит держать эти файлы под рукой при подготовке.

## Статус

Черновик, учебный пример. Текст обзора и ADR написаны ради иллюстрации расхождения между документацией и практикой, а не как реальная документация `pe2030-air-quality-pilot`.
