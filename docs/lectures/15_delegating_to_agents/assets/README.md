# Материалы для лекции 15

## Файлы

- [`agent_backlog_run.md`](agent_backlog_run.md) — предложение AI: журнал и отчёт агента, которому дан широкий, слабо ограниченный мандат на разбор технического долга. Агент реализует подтверждённую работу корректно, но также самостоятельно включает отложенное предложение (кеширование) и удаляет исторические тестовые фикстуры, не входившие в мандат явно. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`scoped_agent_task_example.md`](scoped_agent_task_example.md) — контрпример: та же работа, разбитая на четыре отдельные задачи с явными границами, исключениями и точками остановки — решения, требующие суждения человека, явно переданы ему, а не приняты агентом. Используется в **блоках 4–6**.

## Как использовать на занятии

`agent_backlog_run.md` раздаётся целиком в блоке 1 — важно, чтобы аудитория сначала оценила объём и «чистоту» результата, и только потом, сверяясь с историей issue #23 из лекции 5, нашла расхождение с исходным мандатом. Материал прямо продолжает открытые предложения из [лекции 5](../../05_implementation_without_losing_intent/assets/decomposed_pr_example.md) и фикстуры из [лекции 10](../../10_understanding_before_changing/assets/safe_extension_example.md) — стоит свериться с этими файлами при подготовке.

## Статус

Черновик, учебный пример. Журнал агента и код написаны ради иллюстрации разницы между широким и явно ограниченным мандатом делегирования, а не как рекомендация для реального агентного процесса в `pe2030-air-quality-pilot`.
