# Материалы для лекции 17

## Файлы

- [`ai_two_statements.md`](ai_two_statements.md) — предложение AI: два одинаково профессиональных, фактически точных текста (закрытая служебная записка и публичное заявление), различающихся только тем, что было заложено в промпт. Используется в **блоке 2** сценария ([../script.md](../script.md)).
- [`escalation_example.md`](escalation_example.md) — контрпример: путь между молчаливым согласием и односторонним раскрытием — письменная фиксация несогласия, независимая проверка фактов, поэтапный план раскрытия, следующий уровень эскалации при необходимости. Используется в **блоке 6**.

## Как использовать на занятии

Оба текста из `ai_two_statements.md` раздаются одновременно в блоке 2 — важно, чтобы аудитория не пыталась выбрать «правильный» из двух, а увидела, что правильный ответ не сводится ни к одному из них. Ситуация прямо продолжает находку [лекции 13](../../13_security_as_engineering_activity/) и неопределённые данные [лекции 9](../../09_revisiting_the_original_plan/) — стоит держать эти материалы под рукой.

## Статус

Черновик, учебный пример. Тексты и план написаны ради иллюстрации того, что решение с этическими последствиями не делегируется качеству формулировки, а не как рекомендация по коммуникационной стратегии `pe2030-air-quality-pilot`.
