# Материалы для лекции 18

## Файлы

- [`ai_verified_timeline.md`](ai_verified_timeline.md) — основной пример: точная, подтверждаемая по источникам хронология двух семестров работы над пилотом, честно признающая, чего она не объясняет. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`ai_success_story.md`](ai_success_story.md) — контрфактический пример: что получилось бы, если бы команда вместо хронологии сразу попросила AI готовую «историю успеха» — гладкую, фактически точную в каждом предложении, но систематически опускающую почти все переломные моменты курса. Используется в **блоке 3**.
- [`honest_history_example.md`](honest_history_example.md) — контрпример: структура (не готовый текст) для итоговой защиты, явно включающая разделы о пересмотренных решениях, о том, что пошло не так, и о границах подтверждённого. Используется в **блоке 5**.

## Как использовать на занятии

`ai_verified_timeline.md` раздаётся в блоке 1 сразу после быстрого показа хронологии всех 17 предыдущих лекций — важно, чтобы зал сначала признал хронологию честной и полезной и только затем, отвечая на вопросы блока 2, обнаружил, чего в ней не хватает. `ai_success_story.md` показывается позже, в блоке 3, как гипотетический контраст: та же по существу задача AI, но с другим запросом и качественно другим результатом.

## Статус

Черновик, учебный пример. Оба текста написаны как итоговая иллюстрация сквозной темы курса, а не как реальные материалы для публикации о `pe2030-air-quality-pilot`.
