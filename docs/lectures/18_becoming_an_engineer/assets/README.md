# Материалы для лекции 18

## Файлы

- [`ai_success_story.md`](ai_success_story.md) — предложение AI: гладкая, фактически точная в каждом предложении, но систематически неполная история двух семестров работы над пилотом, опускающая почти все переломные моменты курса. Используется в **блоках 1–2** сценария ([../script.md](../script.md)).
- [`honest_history_example.md`](honest_history_example.md) — контрпример: структура (не готовый текст) для итоговой защиты, явно включающая разделы о пересмотренных решениях, о том, что пошло не так, и о границах подтверждённого. Используется в **блоке 5**.

## Как использовать на занятии

`ai_success_story.md` раздаётся в блоке 1 сразу после быстрого показа хронологии всех 17 предыдущих лекций — важно, чтобы контраст между насыщенной, полной поворотов историей курса и гладким текстом AI был ощутим физически, а не только интеллектуально.

## Статус

Черновик, учебный пример. Оба текста написаны как итоговая иллюстрация сквозной темы курса, а не как реальные материалы для публикации о `pe2030-air-quality-pilot`.
